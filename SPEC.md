# PulseDidgest — Specification (MVP)

Эта спецификация описывает исходный MVP. Текущая реализация уже включает multi-user и digest-доставку; актуальные возможности см. в `README.md` и `PROJECT_MEMO.md`.

## Цель
PulseDidgest — сервис, который:
- собирает сообщения из Telegram-групп,
- фильтрует их с помощью LLM (Gemini) по пользовательским категориям (промптам),
- доставляет подходящие сообщения пользователю через Telegram-бота
  (мгновенно или дайджестом).

## MVP-ограничения
- 1 пользователь (whitelist по Telegram user_id)
- Категория ↔ список групп
- Delivery mode: instant
- Один LLM (Gemini)
- Без UI-админки и веба

## Основные сущности
- User
- Category (prompt)
- SourceGroup
- MessageRaw
- Decision

## Основной сценарий MVP
1. Collector получает сообщение из Telegram-группы
2. Сообщение сохраняется как MessageRaw
3. Сообщение проверяется Gemini по Category.prompt
4. Если pass — отправляется пользователю через Telegram-бота

## Не входит в MVP
- Дайджесты и расписания
- Мульти-пользовательский интерфейс
- Оптимизация производительности
