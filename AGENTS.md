# AGENTS — Rules for Codex

## Общие правила
- Не добавлять функционал, не описанный в текущей задаче
- Не писать бизнес-логику без явного задания
- Не изменять Domain без причины

## Обязательные действия после каждой задачи
1. Обновить TASKS.md:
   - перенести выполненную задачу в Done
   - указать следующую логичную задачу в Next
2. Кратко описать, что было сделано

## Если задача неясна
Остановиться и зафиксировать вопрос в TASKS.md
